# Privacy Policy

Homebridge Nest Bridge is a personal app used only by its owner. It accesses the owner's Google Nest thermostat data (temperatures, modes and setpoints) through Google's Smart Device Management API solely to show and control those thermostats in the owner's Apple Home app.

The data stays on the owner's home Raspberry Pi and Apple devices. It is not sold, shared, or used for advertising, and no data from anyone else is collected.

Use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact: open an issue on this repository.
